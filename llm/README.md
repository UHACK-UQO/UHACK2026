# LLM

Ce dossier contient une plateforme servant de LLM pour aider les participants dans leur tâche.

Ce LLM a plusieurs objectifs : 

- Fournir un outils de recherche web
- Fournir une aide à la compréhension des concepts
- Inciter l'utilisation de notre LLM pour décourager l'utilisation de LLMs extérieurs dans une stratégie de mitigation des impacts de l'IA
